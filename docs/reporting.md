# Reporting and Dashboards

The package includes a suite of report templates suitable for publication, executive briefings, and regulatory compliance. Interactive HTML reports leverage plotly and leaflet for rich visualizations.

## Templates
- `publication_report.Rmd` – PDF/HTML report with publication formatting
- `executive_summary.Rmd` – concise HTML summary for stakeholders
- `compliance_report.Rmd` – outlines regulatory checks and audit trails
- `interactive_dashboard.Rmd` – HTML report with interactive charts

## Visualization Helpers
Functions in `reporting_visuals.R` provide interactive scatter, network, geographic, and time-series plots that can be embedded in reports or Shiny dashboards.

## Automated Insights
`insights.R` offers utilities for statistical significance detection, trend analysis, anomaly detection, narrative generation, and KPI calculations to highlight key findings automatically.
