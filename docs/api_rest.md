# REST API

The health data science API exposes versioned endpoints for healthcare analytics.

## Highlights

- OAuth2/OIDC or API key authentication with rate limiting
- Asynchronous job execution for long-running analyses
- Webhook notifications and FHIR-compatible resources
- Streaming-friendly file uploads and paginated responses
- Real-time updates available over WebSocket at `/v1/updates`

Refer to the autogenerated OpenAPI specification from `plumber` for full
request/response schemas and examples.
